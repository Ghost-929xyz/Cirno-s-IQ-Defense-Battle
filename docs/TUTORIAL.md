# 新手教学关卡

主菜单点击“新手教学”进入独立训练场，共 30 步。完成操作后“下一步”才可点击；每一步均可恢复到该步起点重试。右上角“定位目标”用于矿点、宝箱、驻军、修复和冰桥目标。

覆盖：五选二开局牌；缩放、平移、小地图、全图与回城；单选框选、编队与召回；移动、Shift 连续命令、停止防守、空闲部队；资源占领与宝箱；房屋、兵营、魔力井、科技所；集结、招募、研究；驻军撤出和修复；冰冻、冰墙、冰桥；取消、暂停；攻击移动、集中攻击、防守清剿；伐木、木材与火堆；教学存档与读档。

教学使用固定雾之湖地图，没有自动倒计时进攻。金币至少 3000、BAKA 至少 500；最后一关由玩家主动迎敌，生成三名弱化敌军与一座低生命据点。正式远征规则没有修改。

教学进度保存在 user://tutorial_progress.json，不读写三个远征槽位。F5 保存，教学面板读取；重新进入默认从第一步开始，可随时读取此前教学存档。资源补给和弱敌仅在教学模式生效。

验证：Godot --headless --path . --script tests/tutorial_test.gd

教学提示标题栏可拖动；右上角箭头可向上收起和展开。收起后保留当前步骤、完成提示和展开按钮，不阻塞地图操作。

部队在普通移动、建修和占领过程中会优先处理视野内的敌军，随后继续原任务；Shift 队列保留。空闲部队会主动迎敌；S 停止与 D 原地防守站定攻击，不自动追击。F 攻击移动还会主动攻击沿路敌方建筑。

新增伐木与布置火堆两步。T 派遣空闲部队，C 布置火堆；教学存档保存步骤 key，旧版最后一步可正确迁移。
