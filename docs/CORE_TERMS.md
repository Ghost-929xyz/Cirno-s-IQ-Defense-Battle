# 核心名词表

本表把原策划案中的描述统一为研发、UI、数据表和美术交付都能使用的正式名词。代码字段继续使用英文 ID，策划与界面统一使用中文名。

## 1. 世界观与目标

| 正式名词 | 英文 / ID | 定义 | 游戏作用 |
|---|---|---|---|
| 琪露诺 | `cirno` | 雾之湖的冰之妖精，本作可操作英雄兼主单位，也是关卡生命本体。 | 玩家可右键移动，自动攻击，主动释放技能；生命归零即失败。 |
| 琪露诺生命 | `hero_hp` | 琪露诺当前生命值，初始与上限均为 240，自带 2 点护甲。 | 妖精攻击或漏怪偷走 IQ 时减少；归零立即失败，准备阶段自动回复。 |
| IQ 结晶 | `IQ Crystal` | 凝聚琪露诺智商的冰晶，位于所有路径的终点。 | 妖精抵达后会偷走 IQ，按漏怪伤害扣除琪露诺生命。 |
| 妖精攻势 | `Fairy Assault` | 被琪露诺冰冻后前来讨说法的妖精发起的连续进攻。 | 以 10 个固定波次构成第一关流程。 |
| 雾之湖·浅滩 | `Fog Lake Shallows` | 第一关地图，含四向路径、草地建造位与 IQ 结晶。 | 当前 demo 的唯一战斗关卡。 |
| 博丽灵梦 | `reimu` | 第 10 波 Boss，前来处理雾之湖异变。 | 检验玩家完整构筑、英雄操作与防线韧性。 |

## 2. 资源与状态

| 正式名词 | 英文 / ID | 定义 | 获取与用途 |
|---|---|---|---|
| 漏怪伤害 | `leak_damage` | 妖精抵达 IQ 结晶时对琪露诺造成的生命伤害。 | 按敌人类型结算（6-45 点）；是关卡的主要压力来源。 |
| 冻气 | `frost` | 建造、升级建筑的基础资源。 | 初始 180；准备阶段每秒回复，击杀妖精与波次结算也会获得。 |
| 冰晶 | `ice_crystal` | 精英妖精与波次结算掉落的稀有构筑资源。 | 用于触发“冰晶附魔”三选一。 |
| 波次 | `wave` | 一组按时间、数量、敌人类型生成的妖精攻势。 | 第一关共 10 波，最后一波包含博丽灵梦。 |
| 准备阶段 | `PREP` | 波次之间可建造、升级、移动英雄的阶段。 | 持续恢复冻气，可开始下一波。 |
| 交战阶段 | `COMBAT` | 妖精开始生成并沿固定路径进攻的阶段。 | 防御塔、兵营和英雄自动作战，玩家仍可操作英雄。 |
| 结算阶段 | `FINISHED` | 胜利或失败后的最终状态。 | 停止继续生成敌人并展示结果面板。 |

## 6. 命名规范

- 策划、平衡表和 HUD 使用本表“正式名词”。
- 代码、存档和资源文件名使用英文 ID；同一概念不得新增近义字段。
- `冻气` 只代表可消费资源；`Baka 寒气` 只代表英雄击杀阈值被动，避免混用。
- `琪露诺生命` 是唯一失败条件；`漏怪伤害` 只表示妖精抵达 IQ 结晶时对她的扣血，不要再用 `IQ 伤害`。
- `IQ 结晶` 是地图终点地标，不再是生命值池，避免与旧版 `IQ 核心` 混用。
- `琪露诺`泛指角色时使用全名；特指三种防御塔时必须带“冰锥 / 雾凇 / ⑨式冰炮”前缀。
- 青蛙不再是当前 demo 的敌人。历史资料中的青蛙素材仅保留为旧版本记录，不复用于妖精敌人。
