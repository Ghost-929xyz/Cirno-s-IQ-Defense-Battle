# 远征模式反馈修改

本次根据用户提供的反馈文档及三张示意图修改远征模式。新游戏采用以下规则；旧版玩法文档中与本页冲突的选牌、晋升、科技及指挥界面说明由本页取代。

| 反馈 | 实现 |
| --- | --- |
| 1 手动选取效果牌 | 五张牌点击选二，可先取消再更换；点击确认才应用效果，不再自动随机分配。 |
| 2 单位不叠加 | 场外单位预留独立格子和身体空间，移动执行连续碰撞检查；阻挡时侧移并绕路。新建单位、训练、撤出、闪现、冰面融化及读档均寻找空位置。驻军在建筑内以人数表示。 |
| 3 骑兵区分度 | 五种骑乘单位贴图放大到 140%，身体半径为 0.70 格，普通单位为 0.48 格；骑乘单位的地形间距和鼠标命中范围同步增大。重装步兵和狂战士系列放大到 114%。 |
| 4 边缘移屏 | 指针停在窗口内侧 16 像素的边缘时平移镜头，离开窗口即停止；暂停、战术地图、波次字幕、操作界面上以及拖动操作期间不自动移屏。 |
| 5 固定操作区域 | 底部固定指挥区切换招募、建造和科技；放置建筑、施法不收起面板。Esc 取消指令并清空选择。 |
| 6 经验晋升 | 击杀单位获得其造价等额的累计经验，不扣除晋升经验；严格大于自身造价 3 倍升一级，严格大于 6 倍升二级。一级伤害增加 20%；二级生命上限增加 20%，每秒恢复最大生命的 2%。晋升二级不立即补满新增生命。驻军攻击同样享受一级伤害加成；原有驻军治疗和宝箱奖励保留。 |
| 7 分两次全选 | A 或指挥区按钮第一次选当前兵种的全部场外单位，第二次选全部场外军团。无选择时优先剑士；点击或框选另一组单位后重置。 |
| 8 科技与分支 | 新游戏只显示剑士和弓箭手。新设施科技所造价 240 金、生命 1000，完工后提供 20 容量，开放基础骑兵、刺客和各系研究。进阶单位逐条研究，同节点分叉互斥。招募栏只显示已解锁的兵种。 |
| 9 军团栏 | 左侧可滚动兵种卡显示各类总人数、场外人数和驻军人数，悬停显示晋升人数。点击选中该兵种并定位；全部驻军时定位驻军建筑，可使用撤出按钮。 |

## 研究路线

- 剑士 → 近卫 → 圣骑或重装步兵
- 弓箭手 → 狙击手 → 狙击手+，或弓箭手 → 寒冰弓箭手 → 寒冰弓箭手+
- 骑兵 → 游骑兵 → 斥候，或骑兵 → 枪骑兵 → 具装骑兵
- 刺客 → 隐士 → 隐士+闪避或隐士+突刺，或刺客 → 狂战士 → 狂战士+

界面中的名称以现有数值表为准。“斥候”接入示意图的游射分支，保留当前表格技能；本次未另造第 21 种兵种。研究费用暂按目标原表层级：二层及以下 180 金，三层 240 金。示意图未给出费用，后续可在集中规则中调节。

本次分支研究解锁对应新兵的招募资格，不会自动转换或替换现有单位。互斥选择跨存档、跨远征保留。科技所被摧毁时，基础骑兵与刺客需要重建科技所后继续招募，已完成的进阶研究保留。

骑乘单位继续使用现有角色动画，通过体积和职业字标区分，尚未增加专用马匹动画。旧远征存档保留已有招募进度和单位；旧晋升数值按等级换算为新规则并保留当前生命比例，叠放单位在读档时移至附近空位。
