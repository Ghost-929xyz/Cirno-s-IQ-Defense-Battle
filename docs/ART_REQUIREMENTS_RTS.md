# 东方冰华战线：冰封幻想乡——美术需求文档

版本：2026 年 10 月 10 日。适用范围：基地建设、军团指挥、冰霜魔法与湖岛探索的远征模式。当前已接入 Tiny Swords Update 010 的 63 张源 PNG，具体映射见 [接入说明](TINY_SWORDS_INTEGRATION.md)。

玩法和兵种范围依据《玩法&机制.docx》《数值_初版.xlsx》的已实现版本；制作顺序、画布规格和视觉设计为本项目建议。本文定义待交付素材，不表示这些素材已经制作完成，也不新增玩法或更改数值。

## 统一交付规范

- 风格：俯视偏侧面的像素画，新增素材先匹配 Tiny Swords 的视角、像素颗粒、描边和光照，再加入琪露诺、冰晶与幻想乡湖岸元素。己方青蓝、敌方珊瑚红、中立灰绿、野怪琥珀色为视觉目标；当前原包使用蓝/红/黄，中立建筑以灰绿调色。阵营还须通过旗帜形状、轮廓区分。
- 当前战场为 80×50 逻辑格；TileSet 源瓦片为 64×64，默认每格显示 21 像素，支持 8.6–32 像素缩放，战场视野 1180×660，HUD 悬浮叠加。新增地形必须采用 64×64 网格。现有角色帧为 192×192，建议新增步兵沿用该透明画布；骑兵先以 192×192 做容纳测试，确需扩大时使用 256×256 并在清单声明。画布大小不等于角色实体尺寸，也不等于寻路占地。
- 人物底部中心作为脚点；建筑底部中心作为锚点；帧内留出武器、马匹、特效不被裁切的透明边距。
- 透明 PNG、sRGB；无白底、无预乘黑边、无有损压缩。像素资源关闭平滑插值。人物影子单独一层，不烘焙地面背景。
- 每个动作单独一张帧表，同一方向的帧横向排列。本轮兼容当前方向方案：待机/移动提供侧向并允许左右翻转，攻击按向上、侧向、向下三行交付。受击和死亡至少提供侧向。若武器左右不对称，另交左向素材并声明禁止镜像。完整八方向属于后续扩展，另行交付时固定为 S、SW、W、NW、N、NE、E、SE，不混用两套布局。
- 建议文件结构 `assets/rts/units/<unit_id>/<action>.png`，建筑 `assets/rts/buildings/<building_id>/`，地形 `assets/rts/terrain/`，特效 `assets/rts/fx/`，UI `assets/rts/ui/`。
- 附带清单 JSON 或文本，写明素材 ID、帧宽高、方向行顺序、各行帧数、FPS、锚点、循环与否、攻击释放帧、镜像许可和阵营版本。现有接入点为 `tiny_swords_art.gd`（素材与 SpriteFrames）、`tiny_swords_actor.gd`（角色动作）、`tiny_swords_map.gd`（建筑和动态地形）；新增内容需配置这些映射。地形需在 `tiny_swords.tres` 配置图集与拼接，不直接覆盖原包文件。

## 交付包结构

```text
art_delivery/
  README.md                # 版本、素材清单、已完成/未完成项
  manifest.json            # 切帧、方向、锚点、播放与阵营信息
  previews/                # 原尺寸与实际战场缩放预览
  source/                  # Aseprite/PSD 等可编辑源文件
  png/units/<unit_id>/     # idle、run、attack、hit、death
  png/buildings/<id>/      # construction、complete、damaged、destroyed
  png/terrain/             # 草地、水岸、冰桥、冰墙图集
  png/fx/                  # 技能与状态特效
  png/ui/                  # 头像、图标、效果牌
```

角色样例清单：`id=cavalry`、`frame_size=[192,192]`、`attack_rows=[up,side,down]`、`attack_frames_per_row=6`、`attack_fps=12`、`loop=false`；脚点与释放帧必须填写实测值。若尺寸或方向方案有变，先提供样稿和清单，避免整批素材完成后才发现无法对齐。

## 验收与接入

1. 按上述 ID 检查文件齐全、透明背景正确、帧尺寸统一，提供可编辑源文件与最终 PNG。
2. 在 1180×660 实际窗口检查单位与建筑辨识度，不能只看放大原图。密集场景至少摆放 30 名单位与 5 座建筑。
3. 确认已交付方向的脚点一致、无跳帧、武器和马匹不裁切；攻击释放帧与逻辑命中同步；死亡和倒塌不循环。
4. 检查己方、敌方、中立、野怪的轮廓和标记；低亮度与色觉差异下仍可判断归属。
5. 验证驻军射击、强制撤出、冰墙阻路、冰桥可走、湖岛宝箱等关键画面，不以背景绘画改变实际碰撞和路径。
