# 游戏设计：雾之湖第一关

## 1. 一句话概念

在限定路径上部署不同形态的琪露诺，阻止青蛙偷走她的 IQ。每波结算后选择一条“笨蛋灵感”，让构筑逐渐失控但越来越强。

## 2. 核心循环

1. 布置阶段：观察下一波情报、花费冻气放置或升级琪露诺。
2. 防守阶段：塔自动索敌，敌人沿固定路线接近 IQ 核心。
3. 结算阶段：存活则从 3 个 Roguelike 强化中选择 1 个。
4. 构筑阶段：强化叠加到塔、经济和 IQ 资源上。
5. 重复 6 波，击败蛙王后通关。

## 3. 资源与失败条件

| 资源 | 作用 |
|---|---|
| IQ | 核心生命，初始 20；每只漏过的青蛙扣除不同 IQ，归零失败。 |
| 冻气 | 建造和升级货币，初始 140；击杀奖励，布置阶段每秒回复。 |
| 塔等级 | 1-3 级；提高伤害、射程和攻速。 |

同一只青蛙漏过时，IQ 的直接损失会给出清晰的红字反馈。Boss 漏过会立即损失 5 IQ，但不直接结束。

## 4. 第一关地图

- 名称：雾之湖·浅滩。
- 固定路线，带两个长折返；玩家可在草地格部署。
- 出生点：左侧湖面裂缝。
- 终点：右侧“IQ 结晶”。
- 设计意图：中段折返同时覆盖两条路径，适合教学范围与溅射价值；末段提供高压检验塔的升级成果。

## 5. 玩家单位

### 冰锥琪露诺

- 定位：低价单体输出。
- 特点：射程稳定、单体伤害、适合填满早期空位。
- 弱点：面对铁甲蛙和蛙群时效率下降。

### 雾凇琪露诺

- 定位：范围减速。
- 特点：命中后造成小范围减速，是拉长输出窗口的核心辅助。
- 弱点：直接伤害低，不能单独解决高压波次。

### ⑨炮琪露诺

- 定位：高价范围爆发。
- 特点：攻速慢、伤害高、范围大，适合折返点和密集蛙群。
- 弱点：需要减速或地形配合，否则容易空转。

## 6. 敌人

| 敌人 | 行为 | 教学目的 |
|---|---|---|
| 蝌蚪 | 低血、匀速 | 建立基础输出概念 |
| 跳跳蛙 | 高速、低血 | 检验减速和补刀 |
| 铁甲蛙 | 高护甲、慢速 | 鼓励高单发与混合输出 |
| 冰肤蛙 | 抗减速 | 防止只堆控制塔 |
| 雾之湖蛙王 | 高血、高护甲、抗减速 | Boss 构筑检验 |

## 7. 六波节奏

1. 蝌蚪群：让玩家完成 2-3 次基础建造。
2. 蝌蚪 + 跳跳蛙：第一次速度压力，提示雾凇的价值。
3. 铁甲蛙 + 蝌蚪：第一次护甲压力，提示高单发。
4. 密集混合波：检验溅射和升级投资。
5. 冰肤蛙 + 跳跳蛙：控制抗性出现，要求真实伤害。
6. 蛙王 + 护卫：综合检验，收束第一关构筑。

## 8. Roguelike 强化草案

当前原型已实现：

- 尖锐冰锥：所有琪露诺伤害 +20%，可叠加。
- 绝对零度：减速效果增强，可叠加。
- 冬日补课：冻气恢复速度 +40%，可叠加。
- 更大的笨蛋：溅射半径 +20%，可叠加。
- IQ 结晶扩容：最大 IQ +5，并立刻回复 5 IQ，可叠加。

后续可增加改变塔行为的“质变”卡，例如冰锥三连发、雾凇范围冻结、⑨炮对低 IQ 敌人斩杀。

## 9. 操作

- 左键：选择 HUD 中的塔后，点击草地格建造；点击已有塔则选中。
- 右键 / Esc：取消选择。
- 数字键 1/2/3：切换塔类型。
- 空格：开始下一波；选牌阶段先选择强化。

## 10. 后续爬塔扩展

每层使用相同战斗内核，但通过 `LevelModifier` 改变规则：湖水禁建、暴风雪降低射程、青蛙获得护盾、琪露诺每波换位等。层间保留 IQ、塔的“冰晶记忆”和部分强化，形成一局约 25-40 分钟的爬塔体验。
