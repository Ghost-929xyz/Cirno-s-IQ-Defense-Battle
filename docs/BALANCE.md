# 第一关数值初稿

数值目标：第一次游玩应在第 3-4 波开始感到压力，6 波内允许 2-4 次漏怪；正确混合单体、减速和范围输出时应能稳定通关。

## 初始状态

- IQ：20
- 冻气：140
- 建造阶段冻气回复：4/秒
- 战斗阶段冻气回复：0/秒（只靠击杀）
- 连胜奖励：暂不加入，首关保持稳定。
