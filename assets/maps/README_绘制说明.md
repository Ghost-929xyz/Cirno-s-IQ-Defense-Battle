# 像素画地图绘制说明

游戏启动时会自动读取 `assets/maps/map.png` 这张像素画作为地图。
**你只要替换这张图，游戏里的地图就会跟着变**，不需要改任何代码。

## 基本规则

- **1 像素 = 1 格**。图有多大，棋盘就有多大。
- 只支持 PNG 格式，文件名必须是 `map.png`，放在 `assets/maps/` 目录下。
- 建议尺寸：画得比屏幕略小即可。当前窗口是 1180×660，棋盘居中显示，若图片太大，多出来的部分会被裁掉（本项目目前没有移动视角，图最好不要超过约 30×16 格，具体以画面预览为准）。
- 像素颜色用「近似匹配」（容差约 18%），所以轻微的抗锯齿 / 色差不会导致读不到，但请尽量使用下表的标准色。

## 颜色表

| 用途 | 颜色 | 十六进制 |
|------|------|----------|
| 路径（深色） | 深蓝灰 | `#0a0f14` |
| IQ 结晶（核心） | 亮黄 | `#ffe26b` |
| 琪露诺出生点 | 亮绿 | `#7ef0a4` |
| 空地 / 可建造 | 模板灰 | `#4a5d68` |

> 除以上三种「特殊色」之外，其它任何颜色都会被当作**空地（可建造）**，所以你也可以用任意喜欢的颜色画空地，不一定要灰色。

## 画图要求

1. **核心**：整张图里必须有**且只能有 1 个**黄色格（IQ 结晶）。多个黄色格只认第一个。
2. **路径**：用深色画敌人的行进路线。路径必须是「连通」的，且至少有一个深色格要碰到**地图边缘**（作为敌人的出生入口）。路径会被自动识别出入口，自动从边缘连到核心。
3. **出生点**（可选）：绿色格表示琪露诺出生位置，整张图最多 1 个；不画绿格会自动用默认位置。
4. **路径宽度**：建议 2 格宽左右，太细（1 格）敌人也走得动，但可建造区域会很碎。
5. **建筑物不能压在路径上**：空地才是可以造塔 / 造兵营的地方，路径和核心格、入口格都不可建造。

## 画错了会怎样？

- 图里没有黄色核心格 → 游戏报一个警告，然后**自动回退到内置默认地图**，不会崩溃。
- 图里没有能从边缘连到核心的路径 → 同样回退到默认地图。
- 图片太小（小于 4×4）或不是合法 PNG → 同样回退。

## 参考模板

`map.png` 当前就是一张 20×15 的示例图（内置默认地图按像素画规则生成的）。
你可以直接用 Aseprite、Photoshop、画图等任意工具打开它照着画。

## 快速自检

画完保存后直接启动游戏看效果即可。若想快速验证，也可以运行：
（需要本机已安装 Godot 4.5 命令行）

```
Godot --headless --path . -s .tools/path_test.gd --log-file path_test.log
```

看到 `PATH_OK` 就说明这张图能被正常读取。
