# 冰华远征缺失美术素材需求

本清单对应《玩法&机制.docx》《数值_初版.xlsx》重构后的基地与军团玩法。新战场已用程序图形实现功能，下面列出替换占位所需素材及交付规格。素材不是本次已经制作完成的内容。

优先顺序为 P0 兵种辨识与建筑状态、P1 魔法与探索反馈、P2 装饰与氛围。建议先完成基础剑士、弓箭手、主基地、兵营、房屋、水面与冰面，完成一轮实际尺寸验证后再扩展变体。

## 统一交付规范

- 风格：俯视偏侧面的像素画，冷色湖岸与冰晶建筑；己方青蓝、敌方珊瑚红、中立灰绿、野怪琥珀色。阵营还须通过旗帜形状、轮廓区分，不能只靠颜色。
- 当前战场为 40×25 逻辑格，每格显示 21 像素。建议源地块 24×24；常规步兵源帧 32×32、骑兵 48×48；测试缩放后在单屏仍清晰。不要把源帧尺寸误认为游戏占地。
- 人物底部中心作为脚点；建筑底部中心作为锚点；帧内留出武器、马匹、特效不被裁切的透明边距。
- 透明 PNG、sRGB；无白底、无预乘黑边、无有损压缩。像素资源关闭平滑插值。人物影子单独一层，不烘焙地面背景。
- 每个动画单独一张横向帧表；方向按 S、SW、W、NW、N、NE、E、SE 共八行。每行帧数一致，不足处重复末帧。左右持武器不对称时不得直接镜像。
- 建议文件结构 `assets/rts/units/<unit_id>/<action>.png`，建筑 `assets/rts/buildings/<building_id>/`，地形 `assets/rts/terrain/`，特效 `assets/rts/fx/`，UI `assets/rts/ui/`。
- 附带清单 JSON 或文本，写明帧宽高、方向顺序、帧数、FPS、锚点、循环与否、命中帧。运行时尚无自动图集接入器；交付后需建立 SpriteFrames 并替换 `expedition.gd` 的占位绘制。

## 兵种素材 P0

## 验收与接入

1. 按上述 ID 检查文件齐全、透明背景正确、帧尺寸统一，提供可编辑源文件与最终 PNG。
2. 在 1180×660 实际窗口检查单位与建筑辨识度，不能只看放大原图。密集场景至少摆放 30 名单位与 5 座建筑。
3. 确认八方向脚点一致、无跳帧、武器不裁切；攻击释放帧与逻辑命中同步；死亡和倒塌不循环。
4. 检查己方、敌方、中立、野怪的轮廓和标记；低亮度与色觉差异下仍可判断归属。
5. 验证驻军射击、强制撤出、冰墙阻路、冰桥可走、湖岛宝箱等关键画面，不以背景绘画改变实际碰撞和路径。
6. 接入后重新运行 `tests/rts_test.gd`，并更新 `tests/rts_visual_test.gd` 的截图；逻辑与正式贴图同时通过再替换程序占位。

目前所有“待制作”项目均未调用生成工具制作。本清单仅定义制作与验收范围，不含未经确认的工期、报价或素材授权结论。
