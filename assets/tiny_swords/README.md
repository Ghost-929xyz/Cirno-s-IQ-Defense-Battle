# Tiny Swords Update 010

User-supplied asset pack integrated for the expedition prototype. PNG files are
copied unchanged; `manifest.json` records relative paths and SHA256 hashes.
The selected 63 images support the map and character integration.

Godot uses nearest-neighbor texture sampling. Map tiles are 64×64 and troop
animation frames are 192×192. See `docs/TINY_SWORDS_INTEGRATION.md` in the project
for runtime mappings and the remaining visual proxies.
