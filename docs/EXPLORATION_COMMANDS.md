# 中央营地、探索与部队指挥

2026-10-22。本页覆盖旧文档中的出生点、道路、被动金币和指令说明。

## 开局与战争迷雾

- 确认两张开局牌后直接在地图中央 `(40, 25)` 建立基地，不再选择出生点。
- 中央营地预留干燥空地，四周四支火把提供视野。部队移动可以探索，斥候视野更远。
- 未探索区域完全遮蔽；探索后失去视野的地形保留暗色记忆。敌军、敌方建筑、宝箱在失去实时视野后隐藏，不接受隔雾点击选取。
- 主画面、小地图与战术地图共享视野规则。地图外侧始终覆盖不透明战争迷雾。
- 最小缩放以战场画面与地图尺寸计算，缩到最小时整张地图刚好完整进入画面；宽高比不同产生的两侧余量由迷雾覆盖，不能继续缩小。
- 新生成地图与旧手绘地图均移除道路显示；保留渡桥和通行空间。

## 资源点

每张地图放置九个可从中央营地抵达的资源点：四座金矿、三处魔力泉、两座灵视塔。位置由地图种子确定，开局全部未知。

| 资源点 | 占领效果 |
| --- | --- |
| 金矿 | 每秒 3 金币 |
| 魔力泉 | 每秒 2 BAKA，上限 300 |
| 灵视塔 | 在两种地图上标出全部资源点的类型和位置，不揭开远处地形或敌军 |

选部队后右键资源点，部队抵达并停留 5 秒完成占领。附近有敌人时暂停占领；占领部队离开后未完成的进度清空。占领后不必驻守即可获取收益，建筑化魔力井原有功能保留。

基地不再产生每秒金币。开局补给、击杀和宝箱奖励保留，持续金币来自已占领金矿。资源点不属于建筑，不计入“所有基地与建筑被摧毁”的失败判定。

## 指令

| 操作 | 用法 |
| --- | --- |
| 攻击移动 | F 后左键目标位置；途中遇敌交战，结束后继续前往目标 |
| 停止 | S；终止当前指令并清空队列，可在射程内还击，不追击 |
| 原地防守 | D；保持位置，攻击射程内敌人，不追击或闪现离位 |
| 连续指令 | 按住 Shift 追加移动、攻击、攻击移动、占领、建造、修复、驻军和寻宝指令；普通新指令替换队列 |
| 生产集结点 | 左键选己方基地或兵营，右键设置；Shift＋右键增加路线点，新兵自动执行 |
| 编队 | Ctrl＋0–9 保存，数字键选队，350 毫秒内双击同一数字定位队伍中心；支持小键盘 |
| 编队状态 | 顶部显示人数、总生命百分比与交战状态；悬停查看当前/最大生命 |
| 空闲部队 | I 或点击左侧空闲数量，循环选择并定位；小地图蓝色外圈表示空闲 |
| 受袭提示 | 己方受伤后小地图和战术地图显示红色闪圈，附近提示合并，停止受击 6 秒后消失 |
| 地图指令 | 小地图、战术地图右键下令，支持 Shift 连续指令；左键仍定位镜头 |

A 同类/全军、H 回基地、R 修复等已有快捷键保留。右键友军单选，Shift＋右键友军追加选择。

## 存档与兼容

保存已探索区域、资源归属与发现状态、部队指令队列、生产集结路线、数字编队。读取时重新计算实时视野，已阵亡的编队成员在召回时过滤。

旧远征存档保留原有基地和部队，补齐资源与视野数据；处于旧出生点选择阶段的存档改为中央开局。旧种子的地形按新版中央营地规则重建，道路不再绘制。
