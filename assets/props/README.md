# 资源与营地素材

本目录为用户确认导入的内置 imagegen 生成方案，原 PNG 保留透明通道。

- gold_mine.png：金矿，原预览 exec-798e2020-5c13-432a-bd5e-9da129977358.png。
- mana_spring.png：魔力泉，原预览 exec-18f7449f-5b8a-4aaf-9c34-70c6ef5f654f.png。
- campfire.png：小火堆，原预览 exec-70be2c9c-5605-4f58-9816-e59b1082b531.png。替代立式火把，未采用旧火把预览。

生成提示方向：以 Tiny Swords 草顶建筑和灰紫岩石为风格参考，三分之四俯视、像素块阴影、暖灰石材和木材。金矿为有木梁入口的天然矿石堆；魔力泉为围石泉池、小晶簇和苔藓；小火堆为贴地短木柴、零散围石和低矮火苗。透明背景，无文字和 UI 元素。

渲染由 scripts/effects/resource_art.gd 管理，只读取主体区域以去掉预览留白，不修改原图。默认视角下金矿宽 63px、魔力泉宽 57.75px、小火堆宽 26.25px / 高约 15.42px（包括图内火苗和火星）。动态火星最高至地面以上 16px；最小普通兵种约 19.36px 高。缩放统一跟随地图。

小范围暖光、四粒循环火星和局部热浪随模拟时钟变化，暂停时停止。占领、资源产出和营地视野保留原有规则；资源点击区域扩展覆盖新精灵主体。

## 灵视塔

vision_tower.png 使用已确认预览 exec-4079553c-ac4c-428d-bcd4-1003a5dcd624.png。主体为灰紫石塔、苔藓符文和顶部紫色晶体，与金矿及魔力泉共用色调。默认宽 47.25px、高约 63.66px。

完成玩家占领后，顶部晶体增加局部紫白呼吸辉光与四个微小光点；中立、敌方或迷雾不可见时关闭动态特效。辉光定位按同一素材裁切区域计算，镜头缩放时与晶体对齐；特效时钟跟随模拟时间，因此暂停会静止，读档会根据资源点归属恢复。不添加地面轮廓圈。

## 地图像素、碰撞与归属表现

物件在加载时按地图 64px/格的像素密度采样：金矿宽 192px、魔力泉宽 176px、灵视塔宽 144px，使用最近邻过滤和整数世界坐标。与建筑、部队共用 Y 排序，金币、资源点和火堆共用建筑选中材质；没有常驻圆圈和归属文字。

资源点落地占地为横向三格，火堆和可拾取金币为一格，统一写入 prop_obstacles 和地图 ResourceObstacles 层供寻路读取。部队在邻接格交互，拾取后重建通路；读档会将重叠单位移到最近可站立位置。地图生成只在周边留有通行空间的位置放置资源。

中立金矿入口关闭，占领后开启；魔力泉未占领时水面静止，占领后水面及瀑布产生像素流动；灵视塔沿用占领后的晶体辉光。进度和生命指示统一使用圆角矩形。

关闭矿门采用用户确认的 gold_mine_closed.png（内置 imagegen，exec-bd944988-b6fc-42f7-9264-baa6d20eeff2.png）。保留原矿体及木支架，在洞口内重绘双扇木门、铁铰链、斜撑和接触阴影。未占领时显示新版关闭门，占领后切换原开放洞口，两图共用裁切、尺寸与锚点，已移除程序绘制木条。

游戏头像：assets/ui/cirno_avatar.png，由内置 imagegen 基于 menu_character.png 提取头部，用户已确认采用。提示要求保留脸型、姿态、发型、蝴蝶结与手绘画风，仅保留头像并使用透明背景。cirno_avatar.ico 为构建工具生成的多尺寸 Windows 图标，构建时先更新模板副本资源，再由 Godot 打包。
