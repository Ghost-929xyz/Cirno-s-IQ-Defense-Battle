# 像素画地图绘制说明

游戏启动时会自动读取 `assets/maps/map.png` 这张像素画作为地图。
**你只要替换这张图，游戏里的地图就会跟着变**，不需要改任何代码。

## 画布与格子规则

- **2×2 个图像像素 = 1 个逻辑格**。
- 推荐整张画布尺寸：**256×192 像素**，对应 **128×96 个逻辑格**。
- 当前地图会固定缩放到单屏地图区，不需要移动视角。
- 每个逻辑格必须是一个完整的 2×2 同色块；不要只涂 1 像素，也不要画跨格细线，否则读取可能不稳定。
- 道路建议 **4～5 个逻辑格宽**，也就是画布上的 **8～10 像素宽**。
- 兵营占 2×2 个逻辑格（共 4 格），防御塔占 3×3 个逻辑格（共 9 格），因此道路要预留足够宽度。

## 颜色表

| 用途 | 颜色 | 十六进制 |
|------|------|----------|
| 路径（深色） | 深蓝灰 | `#0a0f14` |
| IQ 结晶（核心） | 亮黄 | `#ffe26b` |
| 琪露诺出生点 | 亮绿 | `#7ef0a4` |
| 空地 / 可建造 | 模板灰 | `#4a5d68` |

> 除特殊色之外，其它颜色都会被当作空地（可建造）。推荐仍使用上表的灰色，便于识别。

## 画图要求

1. **核心**：整张图里必须有且只能有 1 个黄色逻辑格（IQ 结晶）。多个黄色格只认第一个。
2. **路径**：用深色画敌人的行进路线。路径必须四向连通，且至少有一个深色格接触地图边缘作为出生入口。
3. **出生点**（可选）：绿色逻辑格表示琪露诺出生位置，最多 1 个；不画时使用默认位置。
4. **路径宽度**：建议 4～5 格；深色块会被完整识别为不可建造道路。
5. **建筑占地**：兵营 4 格，防御塔 9 格；建筑不能压在道路、核心或其他建筑上。
6. **像素密度**：地图按 2×2 像素块取样，实际每个逻辑格只需保持一个整体色块，不必在格内绘制 1 像素细节。

## 画错了会怎样？

- 图里没有黄色核心格 → 游戏给出警告并自动回退到内置默认地图。
- 图里没有能从边缘连到核心的路径 → 同样回退到默认地图。
- 图片宽高不是 2 的倍数、尺寸小于 4×4 格或不是合法 PNG → 同样回退。

## 参考模板

`map.png` 当前是一张 **256×192 像素**（128×96 格）的示例图，包含四方向道路、核心和出生点。
你可以直接用 Aseprite、Photoshop、画图等工具打开它照着画。

## 快速自检

画完保存后直接启动游戏看效果。若想快速验证，也可以运行：

```
Godot --headless --path . -s .tools/path_test.gd --log-file path_test.log
```

看到 `PATH_OK` 就说明这张图能被正常读取。
