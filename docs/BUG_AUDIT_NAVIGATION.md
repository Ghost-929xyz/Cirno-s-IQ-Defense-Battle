# 寻路修复与回归（2026-11-01）

初检基于 `f7ed525`；提交前已整合最新上游 `8173ba3`，保留其建筑完整占地、资源及树干障碍、局部精细寻路和自动交战。本次主要修复上游仍可复现的断路、出口和对向避让问题。

## 已复现并修复

| 问题 | 原来的触发方式 | 修复后的行为 |
| --- | --- | --- |
| 不可达移动命令挂起 | 点击不连通的陆地，或移动途中被冰墙切断路线 | 拒绝新下达的不可达目的地；已有命令失去通路时结束该段并继续后续队列 |
| 骑兵在终点附近卡住 | 新障碍使终点不能容纳骑兵，但终点重定向仍按步兵半径判断 | 移动和攻击移动共用目标检查，按对应兵种半径重新选择可达位置 |
| 驻军撤出后丢失后续动作 | 手动撤军只设置空闲状态；建筑不存在后也不尝试释放无后续命令的驻军 | 保留并启动后续命令；失去所属建筑的驻军继续尝试安全撤出 |
| 敌营援军绕过墙体 | 弱援军把营地旁的位置吸附至墙外空地 | 与训练共用完整建筑外沿入口搜索；封闭敌营暂停出兵，不产生隔墙援军 |
| 窄通道双向堵死 | 混编部队在部分单格、双格通道中相向堵死，正序或逆序更新均可复现 | 用固定单位 ID 决定让行优先级，短暂后退打破对称；每一步仍检查地形与单位扫掠碰撞 |
| 无安全位置时返回假位置 | 无可用格时返回 `(0, 0)`，非有限位置也会进入网格转换 | 明确返回 `Vector2.INF` 表示失败；调用方先检查是否有安全位置 |

新命令会清除旧的卡住计时和让行状态。已有上游建筑、工地和资源障碍实现继续保留；本次测试按建筑完整占地构造封闭出口，不再假定建筑只占中心一格。
