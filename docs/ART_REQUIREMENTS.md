# 美术素材需求

## 1. 统一视觉方向

- 风格：2D 微俯视、清晰赛璐璐上色、冰蓝主色与湿地绿辅色。
- 战斗可读性优先：妖精、友军、建筑必须在 60 像素格与雾层之上保持轮廓分明。
- 琪露诺三类防御塔应有明显职业剪影：尖锥单体、霜环控制、笨重冰炮爆发。
- 兵营和己方兵种使用“冰晶蓝、雾青色、暴雪紫”三种识别色。
- 正式素材不得直接使用东方 Project 官方图；同人发行前需确认最新二次创作规范。
- 当前原型全部为 `_draw()` 占位图，以下素材是替换正式视觉所需的最小集合。

## 4. 防御塔：三种琪露诺

每种防御塔需要独立的攻击动作与三级视觉成长。三级可通过身体尺寸、底座冰晶数量或披风颜色实现，不必重画整套完全不同的待机动画。

| 防御塔 | 必需状态 | 交付说明 |
|---|---|---|
| 冰锥琪露诺 `tower_icicle` | 待机、攻击、受击、低血、摧毁、三级底座 | 巨大尖锥，快速直刺，最易读的单体职业 |
| 雾凇琪露诺 `tower_rime` | 待机、施法、受击、低血、摧毁、三级霜环 | 雾斗篷与六角霜环，动作较慢 |
| ⑨式冰炮 `tower_baka` | 待机、蓄力、发射、后坐、受击、低血、摧毁 | 夸张炮身，发射前清晰蓄光，后坐带笨拙感 |

建议单帧 128x128，建筑本体保持在 96x96 可见范围。每种需提供不透明度 30% 的正蓝或正红剪影一张，用于快速检查战场辨识度。

## 7. 妖精敌人

普通妖精统一使用 96x96 单帧，Boss 建议 192x192。每种需要待机/移动 6 帧、攻击 6 帧、受击 1 帧、死亡 6-8 帧。

| 敌人 | 外观关键词 | 攻击反馈 |
|---|---|---|
| 露水妖精 `enemy_dew_fairy` | 水滴触角、浅蓝翅膀、圆润 | 小型水弹或近身扑击 |
| 风妖精 `enemy_wind_fairy` | 绿色细翼、速度线、轻盈姿势 | 快速风刃 |
| 岩壳妖精 `enemy_stone_fairy` | 石壳、锅盖、厚重轮廓 | 砸地或近身撞击 |
| 霜灵妖精 `enemy_frost_fairy` | 半透明冰肤、霜晶冠、冷色 | 冰晶短射 |
| 妖精队长 `enemy_fairy_captain` | 金边披风、队长徽记、明显精英轮廓 | 指挥波与强化弹 |
| 博丽灵梦 `enemy_reimu_boss` | 红白巫女服、御币、符札、独立站姿 | 符札齐射、结界、Boss 技能 |

## 11. 命名与交付规范

- PNG、透明背景、sRGB，不带棋盘格。
- 角色锚点为脚底中心；建筑锚点为底座中心。
- 动画帧宽高一致，另交 Aseprite、Spine 或 Godot SpriteFrames 源文件。
- 命名格式：`类别_对象_状态_方向_编号`，例如 `enemy_wind_fairy_move_left_03.png`。
- 每批先交剪影与关键姿势，通过战场缩放检查后再做完整动画。
- 不把角色光效烘焙进身体帧；冰雾、霜环、命中光分别交付，便于 Godot 调色和层级控制。
