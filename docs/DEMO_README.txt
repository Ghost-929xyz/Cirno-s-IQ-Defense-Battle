东方冰华战线：冰封幻想乡 — Windows Demo

解压整个文件夹，双击 Icefront-Demo.exe 即可游玩，无需安装 Godot。
适用：Windows 64 位，支持 OpenGL 3.3 的显卡。

开始：新的游戏 → 选择存档槽 → 选择两张开局牌 → 开始远征。
注意：在已有存档槽创建新游戏会覆盖该槽存档。

左键单选/框选，右键移动、攻击或交互。
Ctrl+数字保存编队，数字选择编队。
F 攻击移动，S 停止，D 防守。
底部指挥栏招募、建造与研究科技。
Q/W/E 使用冰冻、冰墙、冰桥。
滚轮缩放，中键拖动，方向键移动视角，H 回基地。
P 暂停，Space 提前迎敌，F5 存档，Esc 取消操作。

目标：防守六波进攻，随后清剿敌军与敌方建筑。
胜利后可以继续探索；基地和所有己方建筑均被摧毁时失败。

本 Demo 为开发中试玩版本，难度与经济平衡仍在调整。
存档：%APPDATA%/Godot/app_userdata/Icefront-Demo/
Demo 使用独立存档目录，首次启动三个槽位均为空，不读取旧开发版存档。试玩中新建的存档会正常保留。
打包日期：2026-11-01


首次试玩建议先进入主菜单“新手教学”：30 步实操覆盖所有核心操作，可定位目标、重试本步，并使用独立教学存档。

资源点现按占领状态显示：金矿开门、魔力泉流水、灵视塔亮起。资源与火堆不可穿越；教学提示可拖动或向上收起。
建筑碰撞修复：主基地和各类建筑、工地均阻挡行走；部队在外围攻击、维修和驻军。出兵与撤军检查可达出口，旧存档中重叠单位会移到空地。

2026-10-31：游戏与 Windows 程序图标采用琪露诺立绘头像；主菜单档案、设置和局内存读档菜单统一冰蓝面板。右上角菜单可保存/读取，底栏存档打开槽位，F5 快速保存。步兵/骑兵碰撞半径改为 0.34/0.50，编队间距 1.4；新增局部精细绕行，地形碰撞保留。移动指令只显示共用终点，追加指令显示最后终点。

树木碰撞修复：按树干实际位置建立障碍，修正树图相对地图锚点向下两格的偏差；树木、建筑、部队统一按落地位置排序，经过树后时正确遮挡。读档自动移出树干内重叠单位。

寻敌优化：普通移动、建修、占领与拾取途中发现视野内敌军会优先迎战，战后继续原任务及追加路线。空闲部队主动迎敌，侦察兵按其更大视野寻敌；优先攻击敌军，稳定锁定目标，跳过不可到达的敌人。停止/原地防守不主动追击；手动集火敌军保留目标。

伐木与火堆：选中部队后右键树木伐木；或选中树木按 T，派遣最近的空闲部队。单人伐木约 6 秒，多人可协作，每棵树产出 20 木材。按 C 或在建造页选择火堆，点击已探索的陆地空地，消耗 20 木材，部队抵达后生火约 3 秒。火堆占地阻挡行走，点燃后提供视野、火星与热浪。树桩、木材、火堆及生火进度均保存在存档中。草地采用已确认的浅银蓝色像素纹理。

背景音乐：主菜单、探索和波次间播放舒缓的 Electric Sheep；敌军来袭或交战时切换为 Romantic Children 电子编曲，切换约 1.5 秒淡入淡出。敌军清除后恢复舒缓曲，暂停或查看菜单时音乐会自动减弱。
打击音效：近战、弓箭、冰系攻击、倒下、建筑破坏，以及施法和伐木均有声音反馈。密集战斗限制叠音，迷雾和屏幕之外的战斗不会播放音效。
音量：主菜单“游戏设置”或局内菜单“声音设置 / 鸣谢”可分别调节背景音乐、战斗音效和菜单音效，设为 0 静音，设置自动保存。
本作是东方Project非官方二次创作；两首音乐由 Wareya 编曲，原曲由 ZUN 创作。具体来源与授权见同目录“音频素材说明.txt”和“Warsong音频授权条款.txt”。

雪松：树木采用已确认的薄雪、中雪、厚雪三种外观，在地图中固定分布，读档保持一致；尺寸与原树干位置对齐，保留伐木后的树桩和树干碰撞。
