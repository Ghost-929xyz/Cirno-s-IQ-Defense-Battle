# 扩展雾之湖与指挥界面

2026-10-10。地图由 40×25 扩展为 80×50，共 4000 格，面积为原来的四倍。源瓦片仍为 64×64；默认显示每格 21 像素，滚轮可缩放至 8.6–32 像素。全景时隐藏密集兵种字标和建筑血条，保留阵营标记。

## 路线与目标

| 区域 | 路线与用途 |
| --- | --- |
| 北岸 | 第 10–11 行木桥；北岸房屋和林边奖励点；连接北侧敌营 |
| 湖西 | 第 25–26 行木桥；中央房屋与分岔路；过桥后绕湖心岛南侧进入东岸 |
| 南岸 | 第 40–41 行木桥；南侧房屋、湖泊绕行与东南敌营 |
| 横向支路 | 西岸营地间通道、西侧内环、东岸湖畔路和敌后纵向路，允许跨路线调兵 |
| 湖心岛 | 封闭水环内有房屋、奖励与野怪；在西侧水环约 (51,25) 施放一次冰桥即可进入 |

三处木桥独立连接两岸：封闭任意两处，另一处仍能通行。三个湖泊真实参与寻路，限制直线穿越；沙路标示行军方向，路外草地也可通行。树木与碎石为装饰。地图布置包含 3 个基地候选、5 座中立房屋、2 座初始敌营、7 处奖励和 4 个野怪。

敌军从东侧北、中、南三个入口分流。共享拓扑与位置在 `scripts/data/rts_battlefield.gd`；编辑地图使用 `scenes/maps/fog_lake_tiles.tscn`。重建脚本会覆盖该地图，手绘修改前应保存副本。

## 行军速度

速度单位为逻辑格/秒，友军、敌军与代理野怪使用同一兵种规则。原始 Excel 导入值保留于 `resources/rts/units.json`，运行时由 `rts_rules.gd` 的 `MOVE_SPEEDS` 覆盖，因此重新导入 Excel 不会恢复过高移速。减速按调整后的速度继续乘算。

| 兵种 | 格/秒 |
| --- | ---: |
| 剑士 | 1.9 |
| 近卫、圣骑 | 1.8 |
| 重装步兵 | 1.6 |
| 弓箭手、寒冰弓箭手及强化型 | 1.8 |
| 狙击手及强化型 | 1.7 |
| 骑兵 | 2.5 |
| 游骑兵、斥候 | 2.8 |
| 枪骑兵 | 2.4 |
| 具装骑兵 | 2.2 |
| 刺客 | 2.3 |
| 隐士及两个变体 | 2.2 |
| 狂战士及强化型 | 2.1 |

默认视野下约为每秒 34–59 像素。保留骑乘机动优势，但最高移速由原表的 13 降至 2.8 格/秒。该轮调整只覆盖行军速度，长期战斗与经济难度仍需试玩评估。

## 新界面与操作

- 顶部：无边框悬浮名称和经营数值；数字加粗并紧贴最上方。暂停/继续、菜单使用右上角扁平图标，波次和阶段倒计时浮在下一行。
- 战场：延伸至整个 1180×660 画面，HUD 叠在战场上；上下边缘以柔和渐变保证文字辨识度。
- 右下角：圆形战术小地图，显示地形、道路、树木、敌营（红色菱形）、打野点（交叉标记）、奖励与视野范围。完整地图投影至圆内，边角目标不会被裁掉；点击或拖动可定位视野。
- 底部中央：634×86 的精简指挥栏，包含招募、建造、科技、全选、撤出、回基地、存档、Q/W/E 和提前迎敌；详情浮在栏上方，消息浮在左下角。
- 招募：点击“招募军团”展开浮动面板，按步战、远程、骑乘、特战四类筛选，悬停查看实际数值。
- 建造、科技：各自展开独立面板，同一时刻只显示一个；选择建造或魔法后自动收起。Esc 收起面板并取消当前指令。
- 视野：滚轮缩放，中键拖动，方向键平移，H 回基地；暂停时仍可查看地图。
- Tab：展开完整俯瞰地图，再按 Tab/Esc 收起；点击地图定位并收起。俯瞰期间暂缓战斗计时，收起后保留原来的 P 暂停状态。
- 每波提示：全屏暗化 0.38 秒、打字提示 0.90 秒、停留 0.80 秒、淡出 0.65 秒，共约 2.73 秒。自动波次和提前迎敌均播放；动画期间暂缓战斗与指令，结束回归原界面。读取进行中的存档不重播已发生的波次。

## 存档与检查

新 RTS 存档写入 `map_version=2`。旧 40×25 RTS 存档读取后，实体坐标扩大两倍并移动到就近可走地块，保留 ID、资源、队列、驻军与战功；冰桥转换到对应水格，旧临时冰墙清除。新版存档不会再次迁移。旧塔防存档仍由原模式读取。

验证脚本：`tests/expanded_battlefield_test.gd`（连通性、替代渡口、地标、移速、减速、迁移、镜头及屏幕指令）、`tests/tiny_swords_test.gd`（瓦片与动画）、`tests/rts_test.gd`（玩法回归）、`tests/floating_ui_test.gd`（圆形地图点击、Tab、暂停保持、六波动画、打字与淡入淡出、波次队列）。`tests/floating_ui_visual_test.gd` 输出悬浮 HUD、俯瞰地图、动画各阶段与恢复截图。
